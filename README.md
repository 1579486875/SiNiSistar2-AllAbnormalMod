## 一、这是什么

　　给《SiNiSistar 2》做的运行时 Mod：把游戏里全部异常状态（70 种）做成
　　一个可以自由开关、自由调等级的悬浮面板。

　　· 不需要通关解锁图鉴 —— 面板是独立悬浮窗，游戏里按 Home 或 Delete 就能打开
　　· 进图鉴「人物异常状态设定」时也会自动出现，和官方那 4 个开关并存
　　· 状态名自动跟随游戏语言（简体中文下显示中文名，名称随等级变化）
　　· 已启用的状态实时高亮（绿色 = 已开启，金色 = 当前选中行）
　　· 面板可以拖动到屏幕任意位置

　　本 Mod 没有修改游戏任何文件，全部通过游戏公开接口调用。
　　面板关闭时几乎零开销；打开时也只刷新屏幕内可见的那二十来行。


## 二、操作方式

　　面板不读取游戏自身的输入动作，也不占用方向键和 Enter（回车）—— 它们
　　在游戏里分别是菜单导航与对话推进，面板一律不碰，所以操作面板时不会
　　误触游戏原生界面。

　　Home / Delete .......... 开关面板
　　　　　　　　　　　　　　 面板没开时按一下打开；面板已开时按一下关掉，两个键都行
　　Backspace .............. 关闭面板（面板没开时按它没有作用）
　　W / S .................. 上下选择状态
　　A / D .................. 调整严重程度（可按住连发）
　　　　　　　　　　　　　　 主键盘的 - 和 +、右侧小键盘的 - 和 + 同样有效
　　PageUp / PageDown ...... 整屏翻页
　　End .................... 跳到列表末尾
　　鼠标滚轮 ............... 滚动列表（每格 3 行，鼠标要放在面板上）
　　鼠标左键 / 右键点击 ..... 切换该行状态
　　　　　　　　　　　　　　 左键和右键都可以，点一下就切换，同时把它设为当前选中行
　　拖动面板 ............... 在面板顶部信息区或四周边框，按住左键拖动

　　关于拖动
　　　　面板上「点上去本来就没有功能」的地方都能拖，也就是顶部信息区
　　　　（标题 / 计数 / 操作提示那一条）和四周边框。列表区域的点击切换
　　　　完全不受影响。

　　关于面板开关
　　　　Home 和 Delete 两个键都能开关面板：面板关着时按一下打开，开着时
　　　　按一下关掉。笔记本如果没有独立的 Home 键（或者要按 Fn 组合键才
　　　　按得出来），用 Delete 就行。

　　　　为什么不用 Enter：Enter 是游戏的对话推进键，面板开着的时候按下去，
　　　　多半是在推进剧情，很容易顺手把当前选中的那个状态关掉。Home 和
　　　　Delete 在游戏里都没有绑定，按错了也不会影响剧情。

　　关于关闭键
　　　　最早是鼠标右键，后来改成 Delete / Backspace，因为右键太容易误触。
　　　　现在 Home 和 Delete 都能开关面板，Backspace 保留成「只关不开」。

　　面板右上角显示「当前可见序号 / 总数」（例如 1-23 / 70），右侧有滚动条。
　　鼠标悬停到某行即选中（金色高亮），左键或右键点击即可切换该状态。

　　状态列的含义：

　　OFF .................... 当前未启用
　　Lv1 … LvN .............. 已启用，数字是当前严重程度
　　… ...................... 数据正在按需加载，稍等一两秒会自动变成名称和等级
　　✗ ...................... 该状态的自动加载重试用尽了（关掉面板再打开会重新尝试）
　　红色 × ................. 该状态不允许从菜单设置（原因见常见问题）


## 三、安装方法

　　1. 双击运行本文件夹里的 install.bat

　　2. 安装器会自动查找游戏目录（支持 Steam 库、其他盘符、旧版安装：
　　　 优先读 Steam 注册表与 libraryfolders.vdf，再查卸载注册表，
　　　 最后扫常见盘符；找不到时会让你手动输入路径）

　　3. 自动安装三项内容并校验版本，完成后按提示操作即可

　　已经装过旧版本的话不用先卸载：直接拿新版再跑一次 install.bat 就行。
　　安装器会认出当前装的是哪一版，显示「已装 vX  ->  将更新到 vY」，
　　然后只写入有变化的文件（通常几秒钟完事）。

　　安装包已经内置了 MelonLoader 需要的全部 IL2CPP 依赖（Cpp2IL、
　　Unity 依赖、以及生成好的程序集），所以首次启动不需要联网，
　　国内网络同样能直接装好开玩。

　　如果不放心，也可以手动复制 ModData 里的内容到游戏目录：

　　version.dll 和 MelonLoader 文件夹 . 放到游戏根目录
　　Mods\AllAbnormalMod.dll . 放到 游戏目录\Mods\
　　Localize\ZH_CN ......... 放到 游戏目录\Mod\Localize\ZH_CN\


## 四、使用步骤

　　1. 从 Steam（或你的启动器）正常启动游戏。
　　　 首次启动 MelonLoader 会自检一下，随后出现一个 console 窗口、
　　　 生成 MelonLoader\Logs 目录，都属正常现象。
　　　 依赖已经随包带上了，这一步不会联网下载任何东西。

　　2. 游戏内：设置 → 语言 → 简体中文

　　3. 想改状态时，在任何界面按 Home 或 Delete，屏幕右侧会出现
　　　「异常状态设定（Mod）」面板。

　　4. 用 W / S 或鼠标滚轮浏览，用鼠标左键 / 右键点行开关，用 A / D 调等级。

　　5. 位置不合适的话，按住面板顶部或边框，把它拖到顺手的地方。

　　6. 改完按 Home 或 Delete 关掉面板，继续游戏（Backspace 也能关）。

　　面板打开后，屏幕内可见的那几十行会自动按需加载（每 0.15 秒加载一个，
　　不影响帧率）。还没加载完的行右边显示「…」，加载完自动变成状态名和
　　等级，不需要手动操作。


## 五、常见问题

　　Q：面板里只有二十几个状态，往下没有更多？
　　A：面板一屏显示约 23 项，而总共有 70 项，需要滚动才能看全。
　　　 · 按 W / S 移动选择行时，视图会跟着选中行自动滚动
　　　 · 也可以直接滚动鼠标滚轮（每格 3 行）、PageDown / PageUp（整屏翻页）、
　　　　 End（跳到末尾）
　　　 右上角的 1-23 / 70 与右侧滚动条可以确认滚动位置。

　　Q：为什么不能用方向键操作面板？
　　A：方向键在图鉴里被游戏原生列表占用，两边同时响应会互相干扰（你按一下，
　　　 游戏和面板一起动）。所以面板改用 W / S 选择、A / D 与 + / - 调等级，
　　　 鼠标左键 / 右键点击也能直接切换，键盘和游戏互不影响。

　　Q：面板挡住游戏画面了怎么办？
　　A：按住面板顶部那条（标题 / 计数 / 操作提示）或者面板的边框，拖动鼠标
　　　 就能把面板挪走。列表区域的点击仍然是切换状态，不会误触。

　　Q：某一行右边显示的是红色 × 而不是 OFF / Lv1？
　　A：说明这个状态不允许从菜单设置，分两种情况：

　　　 1) 危险状态
　　　　　游戏内部依赖特定演出对象或剧情上下文（例如「触手束缚」类）。
　　　　　这类状态如果强行设置，游戏内部会出错并卡死输入（只能大退），
　　　　　所以 Mod 默认禁止设置它们（显示红色 ×），点击不会有任何反应，
　　　　　也不会调用游戏接口。

　　　 2) 游戏接口拒绝设置的状态
　　　　　首次点击时 Mod 会立即回滚，并把该状态记入
　　　　　游戏目录\Mods\AllAbnormalMod_blocked.txt，之后每次启动都会直接
　　　　　显示 ×，不再尝试。

　　　 如果确实想解除某个状态的屏蔽：用记事本打开
　　　 游戏目录\Mods\AllAbnormalMod_blocked.txt，删掉对应的数字行即可
　　　 （风险自负）。

　　Q：面板文字有点糊、不够锐利？
　　A：最常见的原因是游戏分辨率低于显示器的原生分辨率 —— 这时整个画面
　　　 （包括游戏自己的界面）都会被系统放大，字自然就糊。面板会自动检测
　　　 这种情况，并在标题下方显示一行黄色提示。

　　　 解决办法：游戏内 设置 → 画面 → 分辨率，选显示器原生分辨率
　　　 （例如 2560x1600）。

　　　 面板本身也做了清晰度处理：字号按行高的 60% 取、文字加深色描边、
　　　 画布开启像素对齐、字体优先选游戏里带中文字形的那个，所以即便
　　　 分辨率不高，面板也比一般文字更清楚。

　　Q：面板上的「已挂:N」是什么意思？
　　A：表示角色当前实际挂着的异常状态数量。这个数字由面板自己统计，
　　　 不依赖游戏内部那个不可靠的数组。面板重新打开或换场景时会重新
　　　 统计一次。

　　Q：为什么最后一个异常状态怎么都关不掉？
　　A：这是刻意做的保护措施。游戏里「异常状态设定」这个菜单项在异常状态
　　　 数为 0 时会变灰、玩家进不去，而这时人往往正站在那个界面里 ——
　　　 结果就是界面直接卡死，只能重启游戏。

　　　 所以面板不允许把最后一个状态取消：不管是用 A 键把等级降到 0，还是
　　　 用鼠标左键 / 右键点击，都会被拦下来，面板底部的提示行会给出说明。

　　Q：不孕的加护和丧失加护为什么关不掉？
　　A：这两个是游戏里怀孕机制的一对开关 —— 一个阻止怀孕、一个允许怀孕，
　　　 本身就是要二选一的。所以面板这边强制「有且只有一个」：

　　　 · 想从一个换成另一个：直接点另一个就行，原来那个会自动撤下来
　　　 · 想把最后剩下的那个关掉：会被拦下来，底部提示行会说明原因

　　　 所以这两行「关不掉」是刻意设计，不是卡住了。

　　Q：死亡读档后，之前的异常状态还在？
　　A：这不是 Mod 的问题，是游戏本身的设定：异常状态是存档内容的一部分。
　　　 游戏存档时会把这些状态一起写进去，读档时再按存档恢复 —— 所以只要
　　　 存档那一刻身上带着某个状态，读档后它就会回来。

　　　 想彻底去掉：面板里调成 OFF，然后重新存一次档。

　　　 小提示：不少游戏在过场景、进入新地图时会自动存档。所以「我只是加
　　　 了个状态、走两步就死了，读档怎么还在」，多半是那两步路上已经自动
　　　 存过了。

　　Q：为什么游戏目录里有 Mod 和 Mods 两个文件夹？重复吗？
　　A：两个都不是我们乱加的，是两套不同系统的标准目录，不能合并（合并会
　　　 导致一边失效）：

　　　 · Mod\  —— 游戏官方 mod 系统。放贴图替换（Mod\Player）、语言包
　　　　　　　　　（Mod\Localize），由游戏自己读取。
　　　 · Mods\ —— MelonLoader 插件系统。放 .dll 插件，MelonLoader 固定
　　　　　　　　　只扫这个目录，目录名不可改。

　　　 本 Mod 的两部分恰好分别用到两套系统（语言包走官方，插件走
　　　 MelonLoader），所以都装上了。安装器会自动处理好，日常玩完全
　　　 不需要关心。

　　Q：装过旧版本，怎么更新？
　　A：直接用新版安装包再跑一次 install.bat，不用先卸载，也不用手动删文件。

　　　 安装器会先显示「已装 vX  ->  将更新到 vY」，然后只写入有变化的文件，
　　　 同版本重复运行通常几秒钟就完事。

　　　 这些都会被原样保留：屏蔽清单 Mods\AllAbnormalMod_blocked.txt、
　　　 控制台设置 UserData\Loader.cfg、存档，以及你放在 Mods\ 里的其他插件。

　　　 如果以前用旧版安装器装过两次，MelonLoader\MelonLoader\ 下可能留了
　　　 一套多余的运行时文件（几十 MB）。新版安装器会认出来并自动清掉。

　　Q：首次启动卡在下载 / 连不上 GitHub？
　　A：本包已经把 MelonLoader 需要的 IL2CPP 依赖全部放在 ModData 里了
　　　 （Cpp2IL、Unity 依赖、以及已经生成好的程序集），正常安装的话
　　　 首次启动完全不需要联网。

　　　 如果还是看到下载相关的字样，先确认游戏目录下这几处确实存在：

　　　 MelonLoader\Dependencies\Il2CppAssemblyGenerator\Cpp2IL\Cpp2IL.exe
　　　 MelonLoader\Dependencies\Il2CppAssemblyGenerator\UnityDependencies\
　　　 MelonLoader\Il2CppAssemblies\

　　　 少了就重跑一次 install.bat。

　　　 如果游戏本体更新过（GameAssembly.dll 变了），MelonLoader 会用
　　　 本地自带的 Cpp2IL 重新生成一次程序集 —— 这个过程同样不需要联网，
　　　 只是会多花半分钟到一分钟，属于正常现象。

　　Q：打开面板没反应 / 没看到面板？
　　A：看 游戏目录\MelonLoader\Latest.log，搜索 AllAbnormalMod：

　　　 · 完全找不到 → 检查 version.dll、MelonLoader 文件夹是否在游戏
　　　　　　　　　　 根目录（重跑一次 install.bat）
　　　 · 有 Overlay canvas created 和 Status rows created: 70 → 面板
　　　　 已就绪，按 Home 或 Delete 即可
　　　 · 有 Panel build failed → 把错误内容发给作者

　　Q：状态名是日文 / 英文？
　　A：确认游戏内语言已切换为「简体中文」。Mod 面板标题固定为中文，
　　　 状态名跟随游戏语言。

　　Q：等级上限是多少？
　　A：各状态的等级上限由游戏数据决定（多级状态可以一直往上调，
　　　 再按 - 回到 OFF）。

　　Q：游戏以后更新了，Mod 还能用吗？
　　A：· 小版本更新（1.3.x / 1.4.x）：大概率直接兼容。本 Mod 零 Hook、
　　　　 零文件修改，只调公开接口。
　　　 · 大版本重构（2.0 等）：可能需要适配。Mod 启动时会在日志里输出
　　　　 接口自检结果 —— 自检通过会明确写 OK，失败时请把整段日志发给
　　　　 作者定位。

　　Q：怎么卸载？
　　A：删除游戏目录里的这几项即可：Mods\AllAbnormalMod.dll、version.dll、
　　　 MelonLoader 文件夹。语言包 Mod\Localize\ZH_CN 可留可删。
　　　 游戏本体没有被动过任何文件。

　　　 注意：如果要让 Steam 校验或重新安装游戏，先别急着删这些文件 ——
　　　 Steam 只会覆盖它自己清单里的文件，不会动 Mods\、MelonLoader\
　　　 这些目录。

## 七、技术说明（给好奇的人）

　　· MelonLoader 0.7.3 IL2CPP 注入（version.dll 经 UnityPlayer.dll 的
　　　 VERSION 导入劫持）
　　· 未 Hook 任何原方法、未改游戏一个字节，纯调用公开接口
　　· 界面 100% 运行时自建（UGUI），挂在自己创建的独立画布上，
　　　 不复制、不改动游戏任何界面节点，因此不会影响图鉴、
　　　 也不需要图鉴解锁（只读地借用过一次游戏在用的字体，
　　　 免得面板中文显示成方块）
　　· 输入用自研轮询组件，不依赖游戏内事件系统，也不与游戏按键绑定冲突
　　· 状态数据按需加载：滚到哪加载哪，换场景自动作废缓存重新加载，
　　　 并且有超时作废与重试上限，避免加载不出来时反复请求
　　· 随包附带 MelonLoader 的 IL2CPP 离线依赖（Cpp2IL / Unity 依赖 /
　　　 已生成的程序集），首次启动零下载 —— 这一环原本是要从 GitHub 拉的，
　　　 网络不通时会卡在那里很久

　　　　· 显示 ✗（自动加载重试用尽）的状态，现在关掉面板再打开会重新尝试
　　　　　—— 和说明书里写的对上了。
　　　　· 换场景后「已挂:N」会在游戏数据就绪时重新统计，不再长时间偏小。
　　　　· 安装器：同版本重复运行时不再重写 11 MB 的 version.dll。
　　　　· 文档订正：分辨率提示的触发条件、离线依赖的实际体积、接口自检的
　　　　　说明方式。

　　v1.0.12
　　　　· 修复一个严重问题：给已经挂着的状态调等级失败时，会被误判成
　　　　　「这个状态不能设置」并永久写进屏蔽清单（显示红叉、重启也不自愈）。
　　　　　现在只有「从无到有」都失败才会屏蔽，改等级失败只记日志。
　　　　· 修复面板顶部区域重叠：分辨率提示会和操作提示压在一起，并且盖住
　　　　　列表的第一行。顶部留白相应加大了一点，列表从提示行下方开始。
　　　　· 修复窗口化运行时「分辨率过低」提示一直误报的问题 —— 现在只在
　　　　　全屏模式下才判断，窗口化时不再打扰。
　　　　· 修复「已挂:N」在面板重建之后可能一直显示 0。
　　　　· 修复长按 W/S 时偶尔「按一下跳两行」，以及面板刚打开、还没选过行时
　　　　　按一下 W/S 视口就跳回列表顶部的问题。
　　　　· 修复拖动面板途中把它关掉，再打开时面板会瞬移的问题。
　　　　· 内部清理：删除死代码与重复判断，面板构建失败时的残留也不会再
　　　　　一层层叠在屏幕上。

　　v1.0.11
　　　　· 「不孕的加护」和「丧失加护」现在是一对二选一的加护了。这两个在
　　　　　游戏里是怀孕机制的两个方向（一个阻止怀孕、一个允许怀孕），同时
　　　　　挂上或者一个都不挂，游戏那边的状态都会对不上。所以面板这边做了
　　　　　约束：点其中一个就是直接换过去（自动把另一个撤下来），想把最后
　　　　　剩下的那个也关掉则会被拦下，底部提示行会说明原因。

　　v1.0.10
　　　　· 安装包内置 MelonLoader 的 IL2CPP 离线依赖（Cpp2IL、Unity 依赖、
　　　　　以及已生成好的程序集）。首次启动不再需要从 GitHub 下载，
　　　　　国内网络也能直接装好开玩；如果游戏本体更新过，也会用本地自带
　　　　　的 Cpp2IL 重新生成，全程不联网。
　　　　· 安装器支持更新了：会读出已安装的版本，显示「已装 vX -> v1.0.10」，
　　　　　然后只写入有变化的文件 —— 更新通常几秒钟完成，同版本重复运行
　　　　　则是什么都不做。屏蔽清单、控制台设置、存档都原样保留。
　　　　· 安装器会自动清理旧版留下的嵌套目录 MelonLoader\MelonLoader\
　　　　　（以前重复安装时会被塞进去一整套运行时文件，几十 MB）。
　　　　· 修复安装器重复安装的问题：目标目录已存在时，复制 MelonLoader
　　　　　会被塞成 MelonLoader\MelonLoader 多嵌套一层。

　　v1.0.9
　　　　· 开关面板的键从 Enter 改为 Home / Delete。Enter 同时是游戏的对话
　　　　　推进键，面板开着的时候按下去很容易顺手把一条状态切掉；Home 和
　　　　　Delete 在游戏里都没有绑定。面板关着时按一下打开、开着时按一下
　　　　　关掉，两个键都行（Backspace 仍然是只关不开）。
　　　　　（Home 原来「跳到列表首行」的功能随之取消，End 跳末尾照旧。）

　　　　　项在异常状态数为 0 时会变灰、玩家进不去，而此时界面还停在那里，
　　　　　结果就是卡死、只能重启游戏；现在不管用键盘还是鼠标点击都会被
　　　　　拦下来，并在面板底部提示行给出说明。
　　　　· 鼠标右键现在和左键一样，点击列表行也能切换状态。

　　　　　（拖动区域的判定漏了「必须先在面板内」这一步）。

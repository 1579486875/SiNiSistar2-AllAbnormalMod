# 极端场景压测清单

> 用于「大胆假设、小心验证」式的破坏性测试。
> 自动部分见同目录 `压测.ps1`；下面这些需要真按键，只能人工做。
> 每项都写清了**预期结果**，不符合就是 bug。

## 为什么只能人工

面板的按键读取走 Unity 新版 Input System（Raw Input），
程序注入的按键（`keybd_event` / `SendInput`）**收不到**，
所以开面板、点行、拖动这些必须真手按。

## 一、状态相关

### 1.1 全部 70 项逐个开启到满级

| 步骤 | 预期 |
| --- | --- |
| 打开面板，按住 `S` 逐行下移，每行按 `D` 顶到最高等级 | 每行右边显示 `LvN`，绿色 |
| 全部开完后看右上角 | `已挂:N` 的 N 等于实际开启数量 |
| 观察游戏画面 | 角色外观随状态变化，**游戏不卡、不崩** |

> 游戏的异常状态槽位是固定 20 个，Mod 自己维护真实计数。
> 第 21 个开不起来是**游戏限制**，不是 bug —— 这时 `已挂` 应停在 20。

### 1.2 顶到最高等级

| 步骤 | 预期 |
| --- | --- |
| 选中某行，按住 `D` 不放 3 秒 | 等级快速连跳（约每秒 3 级），到上限自动停 |
| 按住 `A` 不放 3 秒 | 等级快速下降，到 `OFF` 停 |

### 1.3 最后一个状态关不掉

| 步骤 | 预期 |
| --- | --- |
| 只留 1 个状态开启，尝试关掉它 | 关不掉，面板底部出现一行警告 |

> 游戏在「一个异常状态都没有」时 UI 会卡死，Mod 强制保留最后一个。
> 想全关：先把**不孕的加护 / 丧失加护**之外的状态关掉，
> 再切换这两个加护中的任意一个（互斥对，切过去会自动放掉另一个）。

### 1.4 加护互斥

| 步骤 | 预期 |
| --- | --- |
| 开启「不孕的加护」，再开启「丧失加护」 | 前者自动关闭、后者开启 |
| 反过来再切一次 | 同样自动互换 |

## 二、界面相关

### 2.1 疯狂快速开关面板

| 步骤 | 预期 |
| --- | --- |
| 连按 `Home` 50 次（越快越好） | 面板跟随开合，**不卡顿、不叠加出第二个面板** |
| 连按 `Delete` 50 次 | 同上 |

### 2.2 疯狂切换分辨率

| 步骤 | 预期 |
| --- | --- |
| 设置里把分辨率从最高切到最低再切回，重复 10 次 | 每次切完面板自动适配新分辨率（日志打印 `Screen changed to ... rebuilding panel`），**不会越切越卡** |

### 2.3 极低分辨率下操作

| 步骤 | 预期 |
| --- | --- |
| 分辨率调到 720x360，打开面板 | 面板完整落在屏幕内；标题、`已挂:N`、页码三个标签**互不重叠** |
| 按 `S` 走到底、按 `End` 跳到末尾 | 列表正常滚动，页码跟着变 |

### 2.4 拖动

| 步骤 | 预期 |
| --- | --- |
| 按住面板**顶部横条**拖动 | 面板跟随鼠标 |
| 使劲拖出屏幕四角 | 面板被限制在屏幕内，**不会跑丢** |
| 按住**左右边缘**拖动 | 同样能拖 |

### 2.5 滚轮

| 步骤 | 预期 |
| --- | --- |
| 鼠标**在面板上**滚滚轮 | 列表滚动，一格约 3 行 |
| 鼠标**移到面板外**滚滚轮 | 列表**不动**，游戏画面正常缩放 |

## 三、场景与存档

### 3.1 疯狂切换场景

| 步骤 | 预期 |
| --- | --- |
| 反复进出：标题 → 游戏内 → 图鉴 → 战斗 → 读档，来回 20 次 | 面板每次都正常显示状态名（不会卡在 `…`），**不越来越卡** |

## 四、压力与时间

### 4.1 长时间挂机（自动）

`压测.ps1 -IdleMinutes 30`，预期：

- 工作集内存增长 **< 1 MB/min**（正常应接近 0）
- 线程数、句柄数**不持续增长**
- 日志无 error / exception

### 4.2 反复冷启动（自动）

`压测.ps1 -ColdRounds 10`，预期：10/10 全部正常加载出面板。

### 4.3 面板开着挂机

| 步骤 | 预期 |
| --- | --- |
| 打开面板放着 30 分钟不动 | 内存稳定；游戏画面仍正常刷新（面板不阻塞游戏） |
